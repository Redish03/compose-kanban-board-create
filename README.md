# 리팩터링 및 테스트
### 할 일(Task)
- 할 일의 제목 또는 사용자 닉네임이 공백 또는 빈칸일 경우 IllegalArgumentException을 발생시킨다.
- 할 일의 본문 또는 태그들은 원래 nullable이였으나 null일 수 없도록 수정

### 컴포넌트
1. 컴포넌트 분리
- 해당 파일의 컴포넌트와 관련이 없어 분리가 필요하다고 생각한 컴포넌트는 분리
2. 컴포넌트들에 Modifier 주입
3. 컴포넌트 프리뷰 추가
