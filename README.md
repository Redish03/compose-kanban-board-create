# 칸반 보드 생성(상품 목록)

## 기능 구현 사항
- [ ] 제목 입력
  - [ ] 필수 입력이다 
  - [x] 힌트 텍스트 제공
  - [ ] 유효하지 않은 제목을 입력하면 테두리선, 경고 아이콘과 함께 에러 문구를 Supporting text에 띄운다
    - [ ] 아무것도 입력하지 않은 경우 유효하지 않은 제목이다
    - [ ] 공백 또는 빈칸만 있는 경우 유효하지 않은 제목이다
- [ ] 설명
  - [ ] 선택 입력이다
  - [x] 힌트 텍스트 제공
- [ ] 태그
  - [ ] 선택 입력이다 
  - [x] 힌트 텍스트와 Supporting text 제공한다
  - [ ] ','를 기준으로 태그를 생성한다
  - [ ] 유효하지 않은 태그를 입력하면 테두리선, 경고 아이콘과 함께 에러 문구를 Supporting text에 띄운다
    - [ ] 입력된 태그 갯수 검증 (5개 이내)
    - [ ] 하나의 태그의 글자수 검증 (5자 이내)
- [ ] 상태
  - [ ] Todo, In Progress, Done 중 하나만 선택해야 한다
  - [ ] 기본적으로 첫 번째 항목인 Todo가 선택되어 있다
  - [ ] 클릭하면 선택된 항목의 배경과 테두리가 파란색으로 변한다
- [ ] 담당자
  - [ ] 기본적으로 첫 번째 항목으로 선택되어있다
  - [ ] 담당자 중 한 명은 선택되어야 한다
  - [ ] 클릭하면 선택된 항목의 배경과 테두리가 파란색으로 변한다
  - [x] 담당자 수가 많아지면 옆으로 넘겨 선택할 수 있다
- [ ] 생성
  - [ ] 각 컴포넌트들의 유효성이 통과한다면 생성 버튼이 활성화 된다
  - [ ] 할 일을 생성한다
